# Website Profile Đoàn Thanh Niên - Công ty TNHH Thép Tây Đô

Dự án Next.js (App Router) dùng để giới thiệu hồ sơ tổ chức Đoàn Thanh Niên công ty TNHH Thép Tây Đô.

## Công nghệ

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- ESLint

## Nội dung trang chính

- Hero giới thiệu tổ chức
- Giới thiệu tổng quan
- Sứ mệnh - Tầm nhìn - Giá trị cốt lõi
- Hoạt động tiêu biểu
- Ban chấp hành
- Thư viện ảnh placeholder
- Thông tin liên hệ

## Chạy dự án local

```bash
npm install
npm run dev
```

Mở trình duyệt tại địa chỉ `http://localhost:2603`.

## Kiểm tra chất lượng

```bash
npm run lint
```

## Ghi chú

- Dữ liệu nhân sự và hình ảnh hiện đang ở mức mẫu minh họa.
- Có thể thay nội dung trực tiếp trong file `app/page.tsx`.
